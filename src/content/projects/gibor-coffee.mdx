## Executive Overview
GIBOR Coffee Shop was created to solve common usability hurdles in beverage ordering web applications: sluggish image-heavy catalogs, confusing menu categorization, and poor mobile interaction flows.

---

## 1. Problem & Context
- Traditional menu sites often ship uncompressed hero assets resulting in LCP (Largest Contentful Paint) exceeding 4 seconds on 3G/4G networks.
- Users frequently dropped off before selecting custom drink modifiers (sugar/ice levels, toppings).

---

## 2. Technical Decisions & Architecture
- **CSS Grid & Flexbox Modular Layout**: Eliminated bloated CSS frameworks to maintain zero dependency overhead and sub-50KB styling budget.
- **Dynamic Cart State in Vanilla JS**: Implemented an in-memory pub/sub state manager for real-time cart tallying, price computation, and instant modal updates without external library overhead.
- **Asset Optimization**: Converted high-res drink photography into modern WebP/GIF formats with explicit width/height properties to avoid Cumulative Layout Shift (CLS).

---

## 3. Results & Measured Metrics
- **Initial Load Time**: Reduced by **~38%** through image compression and deferred script execution.
- **Task Success Rate**: **83%** of tested users successfully customized and completed their beverage order in under 45 seconds during structured usability testing (12 participants).
- **Zero Layout Shifts**: Achieved CLS of < 0.02 across all responsive viewports.
